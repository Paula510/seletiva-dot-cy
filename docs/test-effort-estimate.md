## Estimativa de Tempo de Teste

Tempo total estimado para o processo completo de testes: **6 horas**

### Como o tempo foi calculado:
A estimativa foi baseada no tempo real utilizado durante a execução do projeto, incluindo:
- Análise do sistema (Sauce Demo)
- Escrita dos cenários
- Desenvolvimento dos testes automatizados
- Organização e documentação

As tarefas foram cronometradas durante o desenvolvimento, e a média de tempo por etapa está descrita abaixo.

## Tempo Total de Execução do Projeto de Testes
**Aproximadamente 6 horas**, distribuídas conforme abaixo:

### 1. Planejamento e Análise dos Testes (1h)
- Análise da aplicação (Sauce Demo) para entender os fluxos principais.
- Definição dos casos de uso mais relevantes para o teste automatizado.

### 2. Escrita dos Cenários de Teste (1h)
- Criação de 4 cenários baseados em funcionalidades críticas: login, erro de login, finalização de compra, e desistência de compra.
- Documentação dos cenários no arquivo `test-scenarios.md`.

### 3. Desenvolvimento dos Testes Automatizados em Cypress (3h)
- Implementação dos testes com boa cobertura funcional e validações claras.
- Execução iterativa para garantir estabilidade dos scripts.

### 4. Organização do Projeto e Documentação (1h)
- Estruturação das pastas.
- Escrita de arquivos como `user-stories.md`, `test-scenarios.md`, e este `test-effort-estimate.md`.
